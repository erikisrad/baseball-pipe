Baseball Pipe

A website by Erik R.

How it works

Baseball Pipe is a web application that provides access to Major League Baseball (MLB) game broadcasts and related media.

  • Each date provides a list of games for that day.

  • Each game provides a list of available broadcasts and media.

  • Each broadcast provides a video (or audio) player that allows multiple custom enhancemments, providing a better viewing experience than the official MLB.tv player.

    • VODs (non-live broadcasts) skip ad breaks.
    • Live games replace ads with a silent countdown until play resumes.
    • Chromecast support is available.
    • Multiple audio options can be swapped in during video playback, including radio broadcasts and Spanish commentary.
    • Subtitles are available.
    • Both variable quality / forced resolution, fps, and bandwidth options are available.

Start with a date

  • Any 8-digit formatted date can be appeneded to the URL to show games on that date.
    • baseballpipe.com/20260822
  • You can also use the keywords "today", "yesterday", and "tomorrow".
    • baseballpipe.com/today
    • baseballpipe.com/yesterday
    • baseballpipe.com/tomorrow

Select a game

  • From a date page, games are displayed in order of start time, converted to your local timezone.
  • If you know the gamePK (unique identifier) of a game, you can go directly to that game page.
      baseballpipe.com/825044
  • You can also append query strings to a date URL to filter directly to a game.
    • team: Filter by team. baseballpipe.com/20260822?team=reds
    • index: Filter by game number, useful for double headers. baseballpipe.com/20260822?team=reds&index=2

Select a broadcast

Multiple broadcasts are available for each game, including video streams and audio only radio broadcasts

If you know the mediaID of a specific broadcast, you can go directly to that broadcast page. (baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c)

You can also append query strings to a game URL to filter directly to a broadcast.

  • type: Filter by media type. (baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?type=tv)
  • side: Filter by home/away broadcast:
  • language: Filter by language. (baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?language=spanish)
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?side=away
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?side=reds
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?side=cin

    These query strings must be combined to filter the broadcasts down to one selection. (baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?type=tv&side=away)
