Baseball Pipe

A website by Erik R.

How it works

Baseball Pipe is a web application that provides access to MLB game broadcasts and related media.

  • The web GUI allows for easy navigation and selection of games and broadcasts.
    • Each date page provides a list of games for that day.
    • Each game page provides a list of available broadcasts and media.
    • Each broadcast page provides a video (or audio) player.
  • Query strings can be used to bypass the web gui, useful for M2M interfaces.
  • This means broadcasts can be piped into other applications, such as VLC.

Baseball Pipe broadcasts aim to provide a better viewing experience than the official MLB.tv player.

  • VODs (non-live broadcasts) skip ad breaks.
  • Live games replace ads with a silent countdown until play resumes.
  • Chromecast support is available.
  • Multiple audio options can be swapped in during video playback, including radio broadcasts and Spanish commentary.
  • Multiple subtitle tracks are available.
  • Both variable quality and forced resolution/fps options are available.

Start with a date

  • Any 8-digit formatted date can be appeneded to the URL to show games on that date (YYYMMDD).
    • baseballpipe.com/20260925
  • You can also use the keywords "today", "yesterday", and "tomorrow".
    • baseballpipe.com/today
    • baseballpipe.com/yesterday
    • baseballpipe.com/tomorrow

Select a game

  • From a date page, games are displayed in order of start time, converted to your local timezone.
  • If you know the gamePK (unique identifier) of a game, you can go directly to that game page.
    • baseballpipe.com/824703
  • You can also append a team query string to a date URL to filter directly to a game.
    • baseballpipe.com/20260925?team=cubs
  • Include an index if there's a double header.
    • baseballpipe.com/20260925?team=cubs&index=2

Select a broadcast

  • Multiple broadcasts are available for each game, including video streams and radio broadcasts
  • If you know the mediaID of a specific broadcast, you can go directly to that broadcast page.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c
  • You can also specify the broadcaster name in a query string.
    • baseballpipe.com/825044?broadcast=reds.tv
  • Other query strings are available, but must be combined to narrow down to one broadcast.
    • baseballpipe.com/825044?type=tv&side=reds&language=english

Tune the broadcast

  • By default, broadcast playback varies in quality based on network speed and screen resolution.
  • You can use query strings to force a specific resoltion.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?res=1920x1080
  • And/Or an FPS.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?fps=60
  • If you want to force the best overall quality, its easier to just force the max bandwidth.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?bw=max

Putting it all together

  • You can stack multiple query string together to go directly to a broadcast
    • baseballpipe.com/20260805?team=dbacks&type=tv&side=home&bw=max
  • Further information is available on the README
    • baseballpipe.com/readme
