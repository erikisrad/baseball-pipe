Baseball Pipe

A website by Erik R.

How it works

Baseball Pipe is a web application that provides access to MLB game broadcasts and related media. The web GUI makes it easy to browse dates, games, and broadcasts — or skip straight past it with a query string, which makes it easy to pipe a broadcast into another application, such as VLC.

A better way to watch

  • The full modern MLB broadcast catalog is available on demand.
  • VODs (non-live broadcasts) skip ad breaks.
  • Live games replace ads with a silent countdown until play resumes.
  • Chromecast support is available via a custom built receiver
  • Multiple audio options can be swapped in during video playback, including radio broadcasts and Spanish commentary.
  • Supports both adaptive stream quality or forced resolution / frame rate.
  • Many other quality of life features, like picture-in-picture, multi-language subtitles, etc!

Quick start

What? Where?
Today's games baseballpipe.com/today
A specific date (YYYYMMDD) baseballpipe.com/20260925
A team's game on that date baseballpipe.com/20260925?team=cubs
A specific broadcast baseballpipe.com/20260822?team=cincinnati&broadcast=reds.tv
A less specific broadcast baseballpipe.com/20260822?team=reds&type=tv&language=english
Only the best resoltion baseballpipe.com/20260925?team=cubs&type=tv&language=english&bw=max
The raw stream, no HTML page baseballpipe.com/20260925?team=cubs&type=tv&language=english&raw=1

Every query string above can be combined, and more are available. See the README for the full query string guide.
