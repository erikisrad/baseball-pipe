Baseball Pipe

Query String Reference

Query strings can be combined on a single URL, and most are forwarded automatically through redirects: a team/index match on the date page carries any game-page filters along with it, and a resolved broadcast match carries raw, ad, direct, res, fps, and bw on to the stream itself.


Date page — /{YYYYMMDD}

The filters below narrow down the list of games on a given day. If one game remains after filtering, the page will redirect to that game. If filters not resolve to a single game, the game at the first index is returned.

Parameter Description Example
team Filters the date page to the game featuring the named team. Should be a substring specific enough to match only one team name: 'cubs' is fine, 'chicago' is ambiguous. ?team=cubs
index Selects the Nth game, using one-based indexing and ordered by start time. When combined with the team filter, it can be useful for filtering around doubleheaders. ?team=cubs&index=2

Game page — /{gamePK}

The filters below narrow down the list of broadcasts for a game. Combine multiple filters until exactly one broadcast remains. Once the filters define only one broadcast, the page redirects to that broadcast.

Parameter Description Example
team Can be carried over from the date page to work as a tie breaker when filtering on the game page. ?team=reds&type=tv
broadcast Substring filter on the broadcast's display name (announcer or network), e.g. 'espn' or 'reds.tv'. ?broadcast=reds.tv
type Filters by broadcast type, e.g. 'tv' or 'fm'. ?team=reds&type=tv
side Filters by home/away, or by a team name/abbreviation. ?side=home&type=tv
flip Inverts the side resolved by side= or by the team=, picking the opposing side's broadcast instead. Useful for watching the opposition's broadcast of your own team's game. ?type=tv&side=reds&flip=1
state Filters by the broadcast's status text, usually 'live' or 'archive'. ?type=tv&side=reds&state=archive
language Filters by broadcast language. ?language=spanish
availability Filters by the broadcast's availability text, e.g. 'out' for out of market games and 'in' for in market games. ?side=reds&availability=in

Broadcast page & stream — /{gamePK}/{mediaId} and the .m3u8 URLs underneath it

Parameter Description Example
raw Skips the HTML player page and redirects straight to the broadcast's master.m3u8 stream URL. ?raw=1
ad Ad-handling mode for the stream: strip removes ad breaks entirely, none leaves them in untouched, fill replaces them with filler video/audio/subtitles. Omitted means automatic: strip for VODs, fill for live games. ?ad=fill
direct Points segment and key URLs at the real upstream CDN instead of proxying them through this server. Will only work outside of a web browser because of CORS headers. If you are able to use this, it will lower your stream latency and save me bandwidth costs, a win/win! ?direct=1
res Restricts the master playlist to a specific resolution. Common options are 320x180, 384x216, 512x288, 640x360, 896x504, 960x540, 1280x720, and 1920x1080. ?res=1920x1080
fps Restricts the master playlist to a specific frame rate. Common options are 30 and 60. ?fps=60
bw Restricts the master playlist to its highest (max) or lowest (min) bandwidth variant. This is the easiest way to force the best overall quality. ?bw=max
tsoffset Advanced/internal. A timestamp offset in seconds applied to filler segments and subtitles for continuity with a livestream. Set automatically by the player itself and not meant for users. filler_003.ts?tsoffset=12.5
