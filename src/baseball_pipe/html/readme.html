Query String Reference

Date page (/20260925)

  • Append a team query string to filter directly to a game on that date.
    • baseballpipe.com/20260925?team=cubs
  • Include an index if there's a double header and team matches more than one game.
    • baseballpipe.com/20260925?team=cubs&index=2
  • The broadcast filters below (broadcast, type, side, state, language, availability) also work directly on a date URL, and carry through to the game they redirect to.

Game page (/825044)

  • Specify the broadcaster name to jump directly to that broadcast.
    • baseballpipe.com/825044?broadcast=reds.tv
  • Other filters are available: type, side, state, language, availability. These must be combined to narrow down to exactly one broadcast.
    • baseballpipe.com/825044?type=tv&side=reds&language=english
  • If more than one broadcast still matches, add a team query string as a tiebreaker.
    • baseballpipe.com/825044?type=tv&team=cubs
  • Narrowing down to exactly one broadcast redirects straight to its broadcast page, carrying along any other query string.

Broadcast page (/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c)

  • Add raw to skip the player page and redirect straight to the playable master.m3u8 URL. Any other query string on the page is carried along onto it.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?raw=1

Tune the broadcast (these work on the broadcast page, master.m3u8, and any rendition playlist underneath it)

  • Force a specific resolution.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?res=1920x1080
  • And/or an FPS.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?fps=60
  • If you just want the best quality, it's easier to just force the max bandwidth. min works too.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?bw=max
  • Control how ad breaks are handled: strip removes them entirely, fill replaces them with a silent countdown, none leaves them untouched. Left unset, VODs strip and live broadcasts fill automatically.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?ad=strip
  • Point real segment and key URLs straight at the upstream CDN instead of proxying them through this server. Mostly useful for debugging; filler segments (used by ad=fill) always stay proxied since they only exist on this server.
    • baseballpipe.com/825044/a80d5e23-ea32-4a02-8aeb-ba11069b049c?direct=1
